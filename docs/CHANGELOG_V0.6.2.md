# Wansan Studio 更新日志 (v0.6.2)

本版本专注于核心编辑体验的极致优化、大宽表操作的便利性以及系统鲁棒性的全方位提升。

## ⌨️ SQL 编辑体验进化
- **编辑器最大化**：QueryPanel 现在支持一键切换全屏编辑模式，为编写复杂逻辑提供广阔视野。
- **长 SQL 阅读优化**：
  - **粘性滚动 (Sticky Scroll)**：滚动时自动吸顶当前代码块头部（如 CTE 命名），上下文永不丢失。
  - **智能缩略图 (Minimap)**：增加代码全局视图，支持快速定位与跳转。
  - **折叠支持**：支持对 `WITH` 子句等区块进行手动折叠。
- **高密度排版风格**：
  - 重构了 SQL 格式化配置，采用“高密度标准流”风格。
  - 显著减少了长 SQL 的纵向行数，减少无效换行，使复杂 CTE 逻辑更紧凑易读。

## 📊 大宽表与预览优化
- **拖拽滚动支持**：DataTable 现在支持鼠标左键“抓取并拖拽”滚动，在大宽表操作时比寻找滚动条更直观、高效。
- **滚动条强制可见**：优化了 Webkit 样式，确保横向/纵向滚动条在 macOS 等系统下不再自动隐藏，提升可发现性。
- **列宽智能分配**：引入 `colgroup` 预设，确保每列拥有合理的最小宽度，防止内容在列数多时产生挤压。
- **布局防冲突**：在聊天面板右侧增加了物理间距，彻底解决了滚动条与面板调整手柄 (ResizeHandle) 的操作冲突。

## 🛡️ 系统鲁棒性与错误处理
- **全局错误详情窗口**：实现 `ErrorDetailModal` 组件。致命错误（如导入/导出失败）现在会弹出专业的警告窗口，支持查看完整日志并一键复制。
- **校验深度提升**：将“类型预检查”的采样行数从 1000 行提升至 **50,000 行**，确保能拦截隐藏在文件深处的类型冲突。
- **错误卡片重构**：统一了聊天流中错误消息的视觉风格，采用深色终端背景展示日志。
- **运行时修复**：
  - 修复了打包后 ASAR 路径下数据库进程初始化失败的问题。
  - 修复了 Markdown 渲染器在接收非字符串数据时导致的崩溃。
  - 修复了洞察面板指令输入框在输入时失去焦点的 Bug。

## 🎨 UI/UX 细节打磨
- **智能 Tooltip**：消息建议列表现在会自动检测文本是否缩略，仅在文字显示不全时才触发悬浮气泡提示。
- **Panel 手柄响应优化**：扩大了面板调整条的点击热区，同时保持视觉线条纤细美观。
- **输入交互修正**：确保通过点击按钮触发 `@数据源` 或 `/指令` 时，光标自动定位并即时呼出建议列表。
- **导出优化**：报告模式下导出 PDF 现在默认采用竖向 (Portrait) 排版，更符合文档阅读直觉。
