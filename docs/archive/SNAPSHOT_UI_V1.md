## 1. 核心布局架构 (Core Layout Architecture)

采用 **"Global Header + Resizable Panels"** 架构，彻底解决窗口拖拽与内容交互的冲突。

### 1.1 尺寸规范 (Dimensions)
*   **Window Size**: Default `1280x800`, Min `1024x600`.
*   **Vertical Rhythm (Key)**: 所有面板的顶部 Header 必须严格统一为 **`h-12` (48px)**。
*   **Panel Default Ratio**: `20% (Left) : 35% (Middle) : 45% (Right)`.

### 1.2 拖拽区域 (Draggable Regions)
*   **允许拖拽**: 仅限最顶部的 **Global Window Header** (`.draggable`).
*   **禁止拖拽**: Global Header 内的按钮、Input，以及所有下层业务面板的 Header (`.non-draggable`).

## 2. 组件详细规范 (Component Specs)

### 🅰️ Global Window Header (Top Bar)
*   **Height**: `h-12` border-b.
*   **Left Zone**:
    *   Padding: `pl-20` (Mac Traffic Light Spacer).
    *   Content: **Editable Project Title** (Input, `text-sm`, transparent).
*   **Right Zone**:
    *   Toggle: Sidebar (`PanelLeft`), Dashboard (`PanelRight`).
    *   Mode: Presentation Toggle (`MonitorPlay`).
*   **Z-Index**: `z-50`.

### 🅱️ Left Panel: Data Source
*   **Content**:
    *   Primary Action: `[+ Import Data]` (Black Button).
    *   Tree View: File hierarchy.
*   **Cleanup**: Removed redundant "DATA SOURCES" static header.

### 🅲 Middle Panel: The Chameleon
此面板根据状态在 "Chat" 和 "Import" 之间切换。

*   **Header**:
    *   Height: `h-12`.
    *   Alignment: Text "Data Import" must be wrapped in `h-8 px-2` to align perfectly with Right Panel's Input.
*   **State: Data Ingestion (Schema Confirm)**:
    *   **Layout**: Edge-to-Edge (No outer padding).
    *   **Table Header**: `sticky top-0`, `z-20`, White background.
    *   **Preview Column**:
        *   Tags: `max-w-[120px] truncate`, `inline-block`.
        *   Data: Must fetch real `sampleValues` from backend.
    *   **Footer**:
        *   Position: `sticky bottom-0` (via Flexbox `mt-auto` or `flex-none`).
        *   Style: `border-t`, `bg-white/95 backdrop-blur`, `shadow-up`.

### 🅳 Right Panel: Dashboard Canvas
*   **Header**:
    *   Height: `h-12`.
    *   Content: Title Input ("Untitled Analysis") + Actions (Zoom, Layout, Export).
*   **Canvas Wrapper**:
    *   Background: `bg-zinc-100` (The Desk).
*   **Paper Element (`#report-canvas-paper`)**:
    *   **A4 Mode**: Fixed `210mm` width, White bg, Drop Shadow (`shadow-md`), Border.
    *   **Screen Mode**: `w-full h-full`, Transparent bg.
    *   **Footer**: "Generated by Wansan" branding (Visible in Export).
*   **Export Logic**:
    *   Snapshot Method: `html-to-image` (Target Paper DOM) -> `jspdf`.

## 3. 视觉与交互细节 (Visual & Interaction Details)

### 3.1 Toast Notifications (Sonner)
*   **Position**: Top Center.
*   **Z-Index**: `z-[99999]` (Must override Global Header).
*   **Style**: `backdrop-blur-md`, `rounded-xl`, `shadow-xl`, `border-zinc-200`.

### 3.2 Modal/Overlay
*   **Presentation Mode**:
    *   Trigger: Button in Global Header.
    *   Behavior: Collapses Left & Middle panels -> Triggers OS Fullscreen.
    *   Cleanliness: Hides Dashboard Local Header when active.

### 3.3 Typography
*   **Font**: Inter / System UI.
*   **Sizes**:
    *   Headers: `text-sm font-semibold`.
    *   Body: `text-sm`.
    *   Meta/Captions: `text-xs text-muted-foreground`.

## 4. 已知限制与边界 (Constraints)
*   **PDF Export**: Text is not selectable (Image-based PDF).
*   **Mac OS**: Requires `titleBarStyle: 'hiddenInset'` in Main Process.
