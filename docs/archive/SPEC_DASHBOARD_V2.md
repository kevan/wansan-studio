# 🛠️ Spec: Dashboard & Layout 2.0 (The "Presenter" Update)

> **Version**: 2.0
> **Date**: 2025-12-10
> **Focus**: Global Layout, Canvas Modes, WYSIWYG Export.

## 1. 🏗️ Global Layout Architecture

We shifted from a contained layout to a **Global Window Header** architecture to solve window drag issues and ensure control persistence.

### 1.1 The Global Header (`h-12`)
*   **Position**: Fixed at the very top.
*   **Mac Compatibility**: Includes `pl-20` spacer for Traffic Lights.
*   **Controls**:
    *   **Left**: Sidebar Toggle (`PanelLeft`).
    *   **Center**: App Title.
    *   **Right**: Presentation Mode Toggle (`MonitorPlay`), Dashboard Toggle (`PanelRight`).
*   **Behavior**:
    *   Header is `.draggable`.
    *   Buttons are `.non-draggable`.

### 1.2 Panel System (Resizable)
*   **Left (Tree)**: Collapsible.
*   **Middle (Chat)**: Collapsible (New in v2).
*   **Right (Dashboard)**: Collapsible.
*   **Presentation Mode**: A special state that collapses **Left** and **Middle** simultaneously, expanding Right to 100%.
*   **App Fullscreen Link**: Entering Presentation Mode automatically triggers OS-level Kiosk Mode via Electron IPC.

---

## 2. 🎨 Dashboard Canvas 2.0

The Dashboard is no longer just a grid; it uses a **"Paper Metaphor"**.

### 2.1 State Management (`useWorkbenchStore`)
```typescript
interface CanvasConfig {
  layout: 'a4' | 'screen'; // Merged from 4 modes to 2
  zoom: number;            // 50% - 200%
  title: string;           // "Untitled Analysis"
}
```

### 2.2 Layout Modes
1.  **🖨️ Print Layout (A4)**:
    *   **Container**: Fixed width `210mm`, Min-height `297mm`.
    *   **Visuals**: White background, Drop Shadow, centered in gray workspace.
    *   **Footer**: Includes "Generated by Wansan" branding at the bottom.
2.  **🖥️ Screen Layout (Fluid)**:
    *   **Container**: `width: 100%`, `height: 100%`.
    *   **Visuals**: Transparent background, No shadow, Edge-to-Edge.

### 2.3 Visual Hierarchy
*   **Outer Shell**: `bg-zinc-100` (The Desk).
*   **Scale Wrapper**: Applies CSS `transform: scale(n)`.
*   **Inner Paper**: The actual DOM node (`#report-canvas-paper`) targeted for export.

## 3. 📤 Export Pipeline (Snapshot Strategy)

We abandoned the native Electron `printToPDF` due to CSS layout conflicts.

### 3.1 The Pipeline
1.  **Target**: DOM Element `#report-canvas-paper` (The White Paper).
2.  **Capture**: `html-to-image` -> High-Res PNG (`pixelRatio: 2`).
3.  **Generate**:
    *   **For Image**: Save PNG directly.
    *   **For PDF**: Use `jspdf` to create an A4 document and embed the PNG as a full-page image.

### 3.2 Advantages
*   **WYSIWYG**: Exact replica of the screen (charts, layout, fonts).
*   **Clean**: No sidebar/chat overlap issues.
*   **Branding**: Automatically includes the footer visible on the "Paper".
