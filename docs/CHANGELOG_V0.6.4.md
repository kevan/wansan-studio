# Changelog v0.6.4

## 🚀 新特性 (New Features)

- **Excel 导出增强**
  - 为“分析对话”和“仪表盘”实现了全新的 Excel 导出功能。
  - **分栏布局**：采用数据左置、视觉（图表+洞察）右置的专业报表排版。
  - **图表自适应**：导出时自动捕获 ECharts 截图，并保持原始宽高比。

- **系统功能**
  - **项目持久化加固**：彻底解决了因文件被锁（如云同步）导致的配置重置问题，引入指数退避重试机制。
  - **优雅退出 (Graceful Shutdown)**：应用退出前会自动等待所有后台保存任务完成，防止数据损坏。
  - **智能命名**：统一了导出文件的命名规则，自动以 Session 标题作为安全文件名前缀。
  - **更新/公告策略**：新增忽略特定版本更新和公告不再显示的功能。

## 🛠 修复与优化 (Fixes & Improvements)

- **UI/UX 打磨**
  - **Markdown 编辑器**：重构 `RuleEditor`，开启工具栏并优化单行文本下的视觉协调感。
  - **报表容器**：优化了只有图表时的底部留白，提升布局平衡感。
  - **图表细节**：全局开启 ECharts X 轴标签 30 度倾斜显示，有效防止长文本重叠。
