# 🛠️ Spec: SQL Lab (Edit & Rerun)

> **Goal**: Allow users to inspect, edit, and re-execute the SQL generated by AI.
> **i18n Requirement**: All UI strings must be localized.

## 1. Interaction Design

### 1.1 Entry Point
*   **Location**: `ReportCard` (Chat Variant).
*   **Trigger**: A "Code" (`<Code />`) icon in the card toolbar.
*   **Action**: Flips the card (or opens a Drawer/Modal) to show the SQL Editor.

### 1.2 The Editor Interface
*   **Component**: `SqlEditor.tsx`.
*   **Lib**: `monaco-editor` (via `@monaco-editor/react`) for syntax highlighting.
*   **Controls**:
    *   `[ Run Query ]` (Primary) -> Triggers `executePlan`.
    *   `[ Reset ]` (Secondary) -> Reverts to AI's original SQL.
    *   `[ Copy ]` -> Copy to clipboard.

## 2. Integration Logic (`use-chat-store.ts`)

We need a way to update the *result* of a message without creating a new message.

```typescript
// Action: updateMessageData
updateMessageData: (messageId: string, newSql: string, newData: any[], newCols: string[]) => void;
```

## 3. Localization Keys (`locales/en/analysis.json`)

```json
{
  "sql_editor": {
    "title": "Edit SQL Query",
    "run": "Run Query",
    "reset": "Reset to Original",
    "copy_success": "SQL Copied!"
  }
}
```

## 4. Implementation Steps

1.  **Install**: `npm install @monaco-editor/react`.
2.  **i18n**: Add keys to `en/analysis.json` and `zh/analysis.json`.
3.  **Component**: Create `src/renderer/src/components/report/sql-editor.tsx`.
4.  **Card Integration**: Add the flip/modal logic to `ReportCard`.
5.  **Execution**: Connect "Run" button to `window.electron.executePlan` and update the store.
