# 📄 Spec: Smart Report (Future Vision)

> **Goal**: Evolve Wansan from a "Dashboard Tool" to a "Report Generator".
> **Target**: Produce professional, narrative-driven HTML reports comparable to high-end consulting deliverables.

## 1. Core Concept: "The Narrative Flow"

Current dashboards are grids of isolated charts. A "Smart Report" is a linear, cohesive story.

*   **Structure**: Header -> Executive Summary -> Chapter 1 (Analysis) -> Chapter 2 (Details) -> Conclusion.
*   **Elements**: Not just Charts, but rich text, KPI groups, comparison tables, and cross-chart insights.

## 2. New Component Architecture

To match the richness of the reference report (`report.html`), we need new Widget types:

### 2.1 Narrative Widget (叙事组件)
*   **Purpose**: Text-heavy insights, not hidden in a collapsible panel.
*   **Style**:
    *   **Insight Block**: Background color, left border accent, icon title (e.g., "Key Findings").
    *   **Recommendation Block**: Green background, actionable list.
*   **AI**: Auto-generated by synthesizing data from neighboring charts.

### 2.2 KPI Group Widget (指标组)
*   **Purpose**: Display dense metrics horizontally.
*   **Features**:
    *   **Progress Bar**: Visual context for percentages (e.g., 35% execution rate).
    *   **Comparison**: "Vs Last Week" or "Converted vs Not Converted" mini-stats.
    *   **Sparkline**: Tiny trend line background.

### 2.3 Section Container (章节容器)
*   **Purpose**: Group related widgets logically.
*   **Visual**: White card background, shadow, title header.
*   **Function**: Acts as a scope for AI analysis ("Summarize this section").

## 3. The "Report View" Mode

Introduce a toggle in the Workbench: **Dashboard View** vs. **Report View**.

*   **Dashboard View**: Free grid, optimized for monitoring. (Current state)
*   **Report View**:
    *   **Linear Layout**: Single column (mostly).
    *   **Auto-Expansion**: All insights are expanded and rendered as Narrative Widgets.
    *   **Styling**: Typography optimized for reading (serif headers, larger body text).

## 4. Global Narrative Engine (The Brain)

A new AI pipeline that runs *after* individual charts are generated.

1.  **Context Collection**: Gather data/insights from all widgets.
2.  **Synthesis**:
    *   **Executive Summary**: "Overall, sales are up 15%, driven by Region A, despite weakness in Region B."
    *   **Cross-Analysis**: "The drop in conversion (Chart 1) correlates with the low execution rate in the 'Closing' phase (Chart 2)."
3.  **Injection**: Insert these synthesized texts into the report flow.

## 5. Theming & Export

*   **Theme Engine**: CSS Variable-based themes (Corporate Red, Tech Blue, Minimalist).
*   **Template System**:
    *   Instead of rendering raw React components into a blank canvas, inject them into a **Semantic HTML Template**.
    *   Support specialized layouts (e.g., A4 paging, Cover Page).

## 6. Roadmap Steps

1.  **v1.5.x (Immediate)**: Force-expand insights in Web Export. (Starting now)
2.  **v1.6**: Introduce "Narrative Widget" and "KPI Group".
3.  **v1.7**: "Report View" toggle and Global Narrative Engine.
