# Wansan Studio Changelog - V0.6.3

## 🚀 核心更新：智能建模 (Smart Modeling)
本版本引入了全新的 **“智能建模”** 流程，将原本隐式的 AI 分析转变为用户可感知的协作过程：
- **主动触发**：支持从侧边栏或聊天空状态手动触发全量数据结构的智能扫描。
- **结果审查**：新增大尺寸审查弹窗，AI 会基于元数据推荐表关联（Relations）和智能指标（Metrics），用户可逐项勾选确认。
- **指标推导**：AI 现在能根据字段语义自动推导出业务指标（如：毛利 = 销售额 - 成本），并附带推理依据。
- **交互优化**：集成了引导、分析中、结果确认三个阶段，流程更顺畅。

## 🏗️ 架构改进：数据一致性 (SSOT)
- **存储优化**：重构了 Store 持久化机制，不再将大量项目数据写入浏览器的 `localStorage`，仅保留项目路径。
- **强一致性**：强制所有核心数据（文件、会话、图表）从磁盘 `.wansan` 包加载，确保文件是唯一的真理来源，彻底消除了刷新页面导致的数据冲突。

## ✨ UI/UX 体验提升
- **设置中心重构**：修复了设置弹窗背景发灰、Tab 被关闭按钮遮挡的样式问题，提升了整体视觉的“空气感”。
- **错误诊断升级**：
  - 能够区分 AI 生成失败与 SQL 执行失败，并提供针对性的修复建议。
  - 优化了错误详情弹窗（ErrorDetailModal）的长日志展示，防止溢出。
  - 增强了长文本在卡片中的自动换行处理。
- **性能优化**：通过对聊天组件进行虚拟化渲染优化（Memoization），大幅提升了长会话下的响应速度。

## 🛠️ 工程化与安全性
- **代码混淆**：实现了主进程与渲染进程的生产环境代码混淆，增强了核心逻辑的安全性。
- **开发加速**：配置开发阶段跳过混淆步骤，显著缩短了 `npm run dev` 的启动时间。
- **隐私导出**：优化了“导出调试日志”功能，仅保留必要配置，严格排除了 API Key 等敏感信息。

## 🌐 国际化 (i18n)
- 补全了 `no_pinned_reports` 等缺失的翻译键。
- 统一了全局术语，如将“Dashboard”在中英文环境下统一对应为“画布/Canvas”。
